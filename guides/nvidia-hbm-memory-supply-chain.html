NVIDIA 沒有記憶體還能造 GPU 嗎？由 HBM 到自研晶片

高端 NVIDIA GPU 需要記憶體，但不是每一顆晶片都一定使用 HBM。GPU 裸晶已有寄存器和 SRAM／Cache；小規模工作可在片上完成，大型 AI 模型則需要外部記憶體提供容量和頻寬。NVIDIA 不生產記憶體，不等於不懂記憶體，而是把 DRAM 製造交給專門供應商，自己負責架構、控制器、封裝整合、軟件和產品設計。

以下為一般教育資訊和情境示例，不是個人化投資或稅務建議。數字和規則會因產品、個人情況及法規而異，請以最新官方資料和產品文件為準。

一、先分清：GPU 裸晶、記憶體、封裝和顯示卡不是同一件東西

問「NVIDIA 的晶片沒有記憶體能否生產」之前，先要把「晶片」拆開。GPU 裸晶內有寄存器、共享記憶體和 L2 Cache 等 SRAM；這些是速度極高但容量有限的片上記憶體。它們可以支撐部分計算，不是完全沒有記憶體。

高端 AI GPU 還會連接外部 DRAM。HBM 把多層 DRAM 以 TSV 垂直連接，再透過非常寬的介面與 GPU 溝通；在先進封裝中，GPU 裸晶與 HBM 會整合在中介層上。GDDR 通常放在顯示卡 PCB 上，圍繞 GPU。手機或部分整合式系統則可能與 CPU 共用 LPDDR 系統記憶體。

因此，「沒有外置記憶體的 GPU 裸晶能否製造」和「沒有記憶體的 AI 加速卡能否按規格工作」是兩個不同問題。晶圓廠可以完成前者，但後者通常不成立。

二、為什麼記憶體對演算法這麼重要？

運算核心像廚房，記憶體像食材倉庫和通道。廚師再多，如果食材放不下、送不進來，仍要停下來等。GPU 的 TFLOPS 再高，資料不能及時送到 Tensor Core，理論算力就不能全部轉化成實際速度。

對 AI 演算法而言，至少要分開三個限制：容量決定模型和中間資料放不放得下；頻寬決定每秒可搬多少權重、啟動值和 KV Cache；延遲及資料位置則影響小批量運算和實時反應。每 byte 資料可完成多少運算，稱為算術強度；強度低時，增加運算核心也不會等比例提速。優化程式時，把資料重用在寄存器、SRAM 和 Cache，往往比單純增加運算核心更有效。

  • 訓練：要處理模型權重、啟動值、梯度和優化器狀態，實際記憶體通常遠高於模型本身。
  • 推論：權重是基本門檻，還要加 KV Cache、批次、上下文長度和框架工作空間。
  • 影像處理：感光元件輸出的每帧畫面都要暫存，HDR、多帧降噪和影片防震更需要連續讀寫。
  • 高效能運算：問題不一定是 FLOPS 不夠，而可能是 memory-bound，即瓶頸在搬資料而不是算資料。

三、用簡單數字看模型容量：權重只是起點

只用 FP16 作簡化示例，每個參數佔 2 bytes。70 億參數模型（7B）單是權重約 14GB；700 億參數模型（70B）約 140GB。這還未計 KV Cache、批次、啟動值、框架工作空間和碎片。

NVIDIA 官方 H200 頁面列出 141GB HBM3e、4.8TB/s 記憶體頻寬。把 70B FP16 的約 140GB 權重與 141GB 對照，就知道為何不能只看「容量剛好夠」：實際部署還要預留其他資料，可能要量化、改變精度、縮短上下文，或用多張卡分工。

H200 的規格同時說明，容量和頻寬是產品設計的一部分，不是買 GPU 時隨便外接一條 RAM 就可以忽略。

四、HBM 和 GPU 如何結合？

HBM 不是 NVIDIA 自己生產的運算核心，而是記憶體供應商製造的堆疊 DRAM。SK hynix 的官方技術資料把 HBM 描述為以 TSV 連接多層 DRAM；Samsung 亦強調堆疊結構和寬介面可支援大量並行資料傳輸。

GPU 內的記憶體控制器負責安排讀寫，Cache 和 SRAM 保留近期常用資料，HBM 提供更大的工作集。當模型或畫面超出片上容量，就要不斷在 HBM 與運算核心之間搬資料。多張 GPU 之間還要靠 NVLink、PCIe 或網絡分工，不能把所有問題都歸咎於 DRAM。

先進封裝把這些部分放得很近，以增加通道數目、縮短連線和降低每 bit 傳輸能耗。這也是為什麼 HBM 的供應不只是一座 DRAM 晶圓廠的問題，還涉及封裝、堆疊、良率、測試和 GPU 平台驗證。

五、如果沒有記憶體，NVIDIA 晶片能否生產？

可以分三個情境回答。第一，沒有 HBM，晶圓廠仍能製造 GPU 裸晶，因為 DRAM 不是 GPU 裸晶的組成部分。第二，若產品設計指定 HBM，缺少合格 HBM 便不能完成相同規格的封裝和出貨。第三，工程上可改用 GDDR、LPDDR 或更大的片上 SRAM，但那是另一個產品設計，容量、頻寬、功耗和成本都會改變，不能假裝性能不變。

如果 SK hynix、Samsung 和 Micron 同時停止供應，現有依賴 HBM 的型號會面對嚴重供應問題。這不代表 NVIDIA 從此不能再設計任何晶片，而是現行產品組合要改規格、重新驗證、尋找其他供應或改變記憶體架構。TSMC 晶圓產能和 CoWoS 等封裝資源同樣可能成為瓶頸。

所以，『三家 HBM 公司消失，NVIDIA 就永久倒閉』說得太絕對；『沒有 HBM 也完全不妨礙出貨』同樣不正確。

六、NVIDIA 為什麼不自己生產記憶體？自行整合不一定省錢

NVIDIA 在 2025 年 Form 10-K 明確表示採用 fabless 製造策略，晶圓由 TSMC 和 Samsung 生產，記憶體向 SK hynix、Micron 和 Samsung 採購，並使用 CoWoS 封裝。文件亦指出，這種安排可避免擁有和營運製造設施的重大成本及風險，讓公司集中於產品設計、品質保證、市場推廣和客戶支援。

自行生產 DRAM 需要長期製程研發、晶圓廠資本開支、設備折舊、良率學習、產能利用率和人才。HBM 還要處理 TSV、堆疊、散熱、封裝和測試。若需求或產品周期判斷錯誤，昂貴產能可能閒置；景氣反轉時，固定成本仍要承擔。

因此，自製不一定比採購便宜。NVIDIA 仍會投入記憶體控制器、介面、Cache、封裝整合和軟件優化，但把 DRAM 製造交給有規模和經驗的供應商。這是供應鏈分工，不是技術缺席。

七、記憶體主要由哪些公司生產？是否只有這三家？

高端 DRAM／HBM 最常見的三大供應商是 SK hynix、Samsung 和 Micron。NVIDIA 的 10-K 亦直接列出這三家公司。它們的官方資料分別確認有 HBM 產品和相關堆疊技術。

世界上還有其他 DRAM 和特殊記憶體公司，但能做 DDR、LPDDR 或利基型 DRAM，不等於能立即量產符合某一代 AI GPU 要求的 HBM。先進節點、堆疊良率、散熱、可靠性、封裝協同和客戶驗證都會限制實際可供應的人選。

所以分析供應鏈時，不應只數全球有幾多記憶體公司，而要問「哪幾家能在指定時間、指定規格和指定數量下，通過這個 GPU 平台的驗證」。

八、普通公司能否做晶片？vivo 為什麼可以做影像處理？

一般公司可以設計晶片，但不等於要蓋晶圓廠。公司可以用 FPGA 驗證演算法，也可以把 ASIC 設計交給 foundry 生產。真正門檻包括架構、IP 授權、EDA 工具、驗證、tape-out、封裝測試、良率、驅動、開發工具和長期軟件維護。與 NVIDIA 競爭通用高端 GPU，還要面對 CUDA 生態和規模差距。

vivo 的 V2 屬於影像專用晶片思路：把拍照和影片所需的特定工作交給專用硬體，而不是設計一枚取代 CPU 或通用 GPU 的全能晶片。手機可在本機處理部分影像流程，因此某些功能不依賴把照片上傳雲端，但這不代表每項 AI 功能永遠離線，也不代表 vivo 自己擁有晶圓廠。

其他公司同樣可以利用現成的 ISP、NPU、DSP 和手機 SoC 做離線影像優化，或在特定功能上開發 ASIC。傳感器、鏡頭、調校、訓練資料、演算法、功耗和散熱往往比「是否自研晶片」更影響最終相片。自研不是照片質素的保證。

九、從投資角度看，最重要的不是背供應商名單

HBM 需求增加不代表每家記憶體公司都必然提高利潤。價格、良率、資本開支、折舊、客戶議價、產品組合和行業周期都會影響回報。供應緊張也不保證 NVIDIA 只能加價轉嫁，因為產品組合、長期採購安排和市場競爭同樣重要。

較穩健的分析順序是：先確認產品需要哪種記憶體，再看供應商能否按規格量產，然後看封裝和晶圓產能，最後才評估收入、毛利和估值。不要由「AI 很流行」直接跳到「任何記憶體股都值得買」。

常見問題

GPU 是否沒有外置記憶體就完全不能工作？

不一定。GPU 裸晶已有寄存器、SRAM 和 Cache，小規模工作可在片上完成。但大型 AI 模型、高清影像及許多高效能運算需要外部記憶體提供容量和頻寬，所以高端產品通常不能脫離外置記憶體。

缺少 HBM 時，NVIDIA 能否繼續造 GPU？

晶圓廠仍可製造 GPU 裸晶，但指定使用 HBM 的封裝和產品不能按原規格完成。改用 GDDR、LPDDR 或更多 SRAM 是另一種設計，性能、功耗和成本會不同。

NVIDIA 自己不做記憶體，是否因為技術不足？

不能這樣推論。NVIDIA 採用 fabless 分工，把晶圓和 DRAM 製造交給專門供應商，自己投入架構、控制器、封裝、軟件和產品驗證。自設晶圓廠需要龐大資本和良率經驗，不一定更便宜。

HBM 供應商是否只有 SK hynix、Samsung 和 Micron？

三大高端 DRAM／HBM 供應商是這三家，但世界上還有其他記憶體公司。關鍵是其他公司能否在指定規格、數量、良率和時間下通過 AI GPU 平台驗證，而不是只看公司數目。

一般公司可否做離線 AI 拍照？

可以。公司可使用手機 SoC 內的 ISP／NPU／DSP，或開發專用 ASIC，把部分降噪、HDR 和影像增強放在本機處理。無需自設晶圓廠，但需要算法、資料、調校、功耗和軟件配合。

vivo 自研影像晶片是否等於自己製造所有晶片？

不是。自研通常指自行定義和設計專用功能，不代表擁有晶圓廠或所有製程。它與 NVIDIA 通用 GPU 的目標不同：影像晶片專注特定工作，通用 GPU 則服務大量圖形、AI 和計算應用。
